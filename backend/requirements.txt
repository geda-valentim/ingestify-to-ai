# ---------------------------------------------------------------------------
# Ingestify - the default dependency set.
#
#     pip install -r backend/requirements.txt
#
# This file is deliberately a single `-r` line. The name `requirements.txt` is
# the one every reader, every tutorial and every piece of tooling reaches for,
# so it has to be the CORRECT thing to install rather than a trap you avoid by
# having read the docs first. It points at the CPU set, which is the right
# answer for every machine without an NVIDIA GPU - i.e. almost all of them.
#
# The shared package list itself lives in `requirements-base.txt`; that file
# names no index and no torch build, so it can be reused unchanged by both the
# CPU and the CUDA sets.
#
#   backend/requirements.txt               -> CPU (this file, the default)
#   backend/requirements-cpu.txt           CPU only, explicit
#   backend/requirements-vision.txt        CPU + Florence-2 vision extra
#   backend/requirements-cuda.txt          NVIDIA GPU
#   backend/requirements-vision-cuda.txt   NVIDIA GPU + Florence-2 vision extra
#   backend/requirements-base.txt          shared package list, no torch index
#
# GPU users: read docs/GPU.md before installing anything.
# ---------------------------------------------------------------------------

-r requirements-cpu.txt
