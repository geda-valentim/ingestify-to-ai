# ---------------------------------------------------------------------------
# Ingestify - CPU dependency set (THE DEFAULT)
# ---------------------------------------------------------------------------
# Install with:
#     pip install -r backend/requirements-cpu.txt
#
# Why this file exists
# --------------------
# torch is not a direct dependency of this project: it arrives transitively
# through docling (docling -> docling-slim[standard] -> torch>=2.2.2,<3.0.0).
# On plain PyPI that requirement resolves to the CUDA build of torch, which
# drags ~1.66GB of `nvidia-*` + `triton` wheels (~3.4GB installed) onto every
# Linux machine - including a laptop with no GPU at all.
#
# `--extra-index-url` does NOT fix this: the same torch version exists on both
# indexes and pip is free to take either. The only reliable mechanism is a
# PRIMARY `--index-url` pointing at the PyTorch CPU index, with PyPI demoted to
# the extra index, plus an explicit torch pin so docling's transitive
# requirement is already satisfied by the time docling is resolved.
#
# The result is the same upstream torch version as the CUDA build - identical
# Python code, different compute backend.
# ---------------------------------------------------------------------------

--index-url https://download.pytorch.org/whl/cpu
--extra-index-url https://pypi.org/simple

torch==2.13.0
torchvision==0.28.0

-r requirements.txt
