# BASE dependency set - the shared package list. Do NOT install it directly.
#
# It names no index and no torch build on purpose, so the CPU and the CUDA sets
# can both reuse it unchanged. torch is never named here either, but it arrives
# transitively via docling -> docling-slim[standard] -> torch. Resolved from
# plain PyPI that lands on the CUDA build and pulls ~1.66GB of nvidia-* wheels
# onto a machine that may have no GPU - including, in the current resolution,
# the `nvidia-cudnn-cu13` tree that breaks ctranslate2 / faster-whisper with
# `Unable to load libcudnn_ops.so.9` (see requirements-cuda.txt).
#
# That is why this file is not the one called `requirements.txt`. Install one
# of these instead - each configures a torch index and pins torch explicitly at
# top level, so docling's transitive requirement can only resolve to that build
# (the mechanism is spelled out in requirements-cpu.txt):
#
#   backend/requirements.txt               CPU - the default, an alias of below
#   backend/requirements-cpu.txt           CPU only, explicit
#   backend/requirements-vision.txt        CPU + Florence-2 vision extra
#   backend/requirements-cuda.txt          NVIDIA GPU
#   backend/requirements-vision-cuda.txt   NVIDIA GPU + Florence-2 vision extra
#
# See docs/GPU.md.
# ---------------------------------------------------------------------------
